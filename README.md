## 🔨 만들고 있는 것

### 📈 Stock AI — 나만의 주식 리서치 앱

> 숫자는 코드가 계산하고, 해석은 AI가 돕고, **사고파는 판단은 내가** 합니다.

- **살아 있는 기업 보고서** — 미국·한국 500여 개 기업의 공시·재무·주가를 모아, 회사·사업·경쟁우위·가치평가부터 투자 가설과 무효 조건까지 한 문서로 관리
- **새 실적이 나오면 다시 쓰기** — 분기 실적이나 급변이 생긴 보고서를 골라 다시 쓰고, 옛날 이야기는 공개 자료로 사실 확인
- **매수 계획과 상태 계산** — 미리 정한 매수가·손절 조건과 지금 가격을 비교해 `대기 → 접근 → 도달`을 코드가 판정 (매수 신호가 아니라 내 계획의 점검표)
- **매일 아침** — 시장 한눈에(공포·탐욕 지수, 금·은, 환율, 비트코인), 아침 브리핑, 지금 뜨는 종목, 보유 종목 실시간 시세

<sub>개인 자료가 들어 있어 저장소는 비공개입니다.</sub>
